# Pyramid Labs — شركة AI حقيقية (نسخة Vercel)

موظفين (Gemini / DeepSeek / Grok / OpenRouter / Groq) بيشتغلوا فعلاً: بيكتبوا **مستندات وخطط وكود ونصوص**، بيقروا شغل بعض ويعدّلوه، بيوزّعوا مهام على بعض، وانت المدير بتطلب وبتراجع وتعتمد.
المحاكاة بتشتغل **جوه المتصفح**، وفانكشن واحدة على Vercel (`api/llm.js`) بتوصّل الطلبات للمزوّدين. **الشركة شغّالة طول ما الصفحة مفتوحة.**

## هيكل الملفات على GitHub (لازم بالفولدرات)
```
vercel.json
package.json
api/llm.js
public/index.html
public/engine.js
```
## النشر
1. ارفع الفولدر على GitHub بنفس الهيكل ده.
2. Vercel ← New Project ← اختار الريبو ← Framework: **Other** ← Deploy (مفيش Build Command ولا Environment Variables).
3. افتح الرابط ← ⚙ الإعدادات ← حط المفاتيح ← "اختبار" ← احفظ.

## لو المفتاح "مش بيشتغل"
- **شريط أحمر "فانكشن الوسيط مش شغّالة"** = الملفات اترفعت من غير فولدر `api` / `public` (شوف الهيكل فوق).
- في ⚙: زر **اختبار** بيقولك السبب بالظبط (401 مفتاح غلط · 402 رصيد خلصان · 403 مفيش صلاحية · 429 كوتة).
- أسماء الموديلات بتتغير والقديم بيتشال: زر **جلب الموديلات** بيجيب المتاح لمفتاحك، والنظام بيحوّل تلقائياً لموديل شغّال لو الاسم المضبوط اترفض.
- DeepSeek وGrok غالباً محتاجين رصيد في حسابك؛ Gemini عنده باقة مجانية (حدودها بتتغير).

## إزاي تشغّلهم فعلاً
- **تبويب المدير ← مهمة جديدة**: اكتب العنوان + التفاصيل (الشكل والطول واللغة). الموظف بيكتب المخرج كمستند.
- **تبويب 📁 المخرجات**: كل المستندات بنسخها. افتح مستند ← اقرا ← **اعتماد** أو **طلب تعديل** (التعليق بيوصل للموظف ويشتغل عليه). تنزيل .md لكل مستند أو لكلهم.
- **📎 مستند مرجعي**: الصق معلومات/بيانات/متطلبات عن مشروعك؛ الفريق بيقراها في كل دور (للقراءة بس).
- الموظفين بيقروا مستندات بعض ويراجعوها ويعدلوها، وممكن واحد يعمل مهمة لزميله (delegate).
- **حدود صريحة:** هما موديلات نصية: بيكتبوا ويحلّلوا ويصمموا خطط وكود، لكن **مابيشغّلوش الكود ولا بيتصفحوا النت ولا بيبعتوا إيميلات**. اللي بيطلع منهم نص تراجعه وتستخدمه انت.

## ملاحظات
- **المفاتيح** في متصفحك بس (localStorage) وبتتبعت مع كل طلب لفانكشن موقعك بدون تخزين. **البيانات** في IndexedDB على نفس المتصفح؛ اعمل تصدير JSON من وقت للتاني.
- **الصفحة لازم تفضل مفتوحة** (والتاب ظاهر أحسن). الساعة بتقف لما موديل بيفكر.
- افتراضي: ١٠ دقايق مشاهدة = يوم، والموظف بيفكر كل دقيقتين. كتابة المستندات بتخلّي الطلبات أطول وأغلى في التوكنز: زوّد "دقايق بين التفكير" لو الحدود المجانية ضاقت.
- فانكشن Vercel مهلتها ٣٠٠ ثانية (Hobby مع Fluid compute، الافتراضي في المشاريع الجديدة). لو Vercel اشتكى من القيمة وقت النشر، غيّرها لـ 60 في `vercel.json`.
- كل موظف له شخصية وموديل مختلفين، فمتعرفش تنسب الفرق في السلوك للموديل وحده. الموديلات بتنتج نص مناسب للدور، مش مشاعر حقيقية.
