# Pyramid Labs — محاكاة شركة بـ AI (نسخة Vercel)

المحاكاة كلها بتشتغل **جوه المتصفح**، وفانكشن واحدة على Vercel (`api/llm.js`) بتوصّل الطلبات للمزوّدين (Gemini / DeepSeek / Grok / OpenRouter / Groq).
مفيش سيرفر شغّال ولا قاعدة بيانات: **الشركة شغّالة طول ما الصفحة مفتوحة**، ولما تقفلها بتتجمّد وتكمّل من مكانها (البيانات في متصفحك).

## النشر على Vercel
1. ارفع الفولدر ده على GitHub (أو شغّل `npx vercel` من جواه).
2. في Vercel: New Project → اختار الريبو → Framework: **Other** → Deploy. مفيش Build Command ولا Environment Variables.
3. افتح الرابط → اضغط **⚙ الإعدادات** → حط مفاتيح الـ API (وتقدر تضغط "اختبار" لكل واحد) → احفظ.
   - للتجربة بدون مفاتيح: زر "جرّب بموديلات وهمية".
- محلياً: `npx vercel dev`.

## ملاحظات مهمة
- **المفاتيح** بتتخزن في متصفحك بس (localStorage) وبتتبعت مع كل طلب لفانكشن موقعك. مش بتتسجل ولا بتتخزن في سيرفر. كل جهاز بيحط مفاتيحه بنفسه.
- **البيانات** (الرسايل، الأفكار، التقييمات) في IndexedDB على نفس المتصفح/الجهاز. مسح بيانات الموقع = مسح التجربة، فاعمل تصدير JSON من وقت للتاني (⚙ الإعدادات ← البيانات).
- **الصفحة لازم تفضل مفتوحة**. لو التاب في الخلفية المتصفح بيبطّئه فالوقت بيمشي أبطأ؛ الأفضل تسيبه ظاهر.
- **الوقت مفتوح**: مفيش نهاية. افتراضي: ١٠ دقايق مشاهدة = يوم، والموظف بيفكر كل دقيقتين (من الإعدادات).
- لما موديل بيفكر الساعة بتقف لحد ما يخلص (شارة "بيفكر…" فوق).
- **الحدود المجانية**: ٣ موظفين × دور كل دقيقتين ≈ ٩٠ طلب لكل يوم. لو ظهرت أخطاء 429 في الـ feed زوّد "دقايق بين تفكير الموظف". كل مزوّد بيغيّر باقته المجانية، فراجع حسابك.
- فانكشن Vercel عندها مهلة ٦٠ ثانية للطلب الواحد.

## نقطة علمية
كل موظف له شخصية مختلفة وموديل مختلف، فمتعرفش تنسب الفرق في السلوك للموديل وحده. لتجربة أنضف استخدم نفس الشخصية للكل، أو كرر التجربة وبدّل الشخصيات بين الموديلات. الموديلات بتنتج نص مناسب للدور، مش مشاعر حقيقية.
